# INSIDE TECH

IT технологияларын ішінен зерттеуге арналған 3D оқу платформасы. Оқушы технологияның қалай жұмыс істейтінін көреді, параметрлерді өзгертеді, қателеседі, оны түзетеді және соңында өзі жасап шығады.

## Оқу жолы

Басты беттегі үш актілі оқиға оқушыны чиптің сыртымен таныстырады, ішкі блоктарын ашады және сигналдың AI блогына қалай кіретінін көрсетеді. Атластан зертхананы таңдап, алғашқы сабаққа өтуге болады.

Каталогта он зертхана бар. Әрқайсысында сегіз сабақ, көбінде автоматты тексерілетін есептер жиыны бар.

| Бағыт | Зертханалар |
| --- | --- |
| Бағдарламалау | Жасанды интеллект, веб, ойын әзірлеу, алгоритмдер |
| Жүйелер | Компьютер архитектурасы, дерекқорлар, компьютерлік желілер |
| Қолданбалы технологиялар | Киберқауіпсіздік, Cloud & DevOps, робототехника және IoT |

- **«Бір басудың саяхаты»** бір пернені басудан басталған сигналдың жолын 185 мс мысалы арқылы көрсетеді. Басты мәзірден «Саяхат» тармағын аш.
- **«Қара жәшік»** ойынында қосқыштарды ауыстырып, жасырын ережені анықтайсың. AND, OR және NOT элементтерінен сұлба құрастыр. Қате болжамға ойын қарсы мысал береді. Кіру жолы: Computer Architecture бетіндегі «Қара жәшік ойыны» сілтемесі немесе `/blackbox`.
- **Lesson Creator** арқылы `/create` бетінде кодсыз сабақ құрастыр. Кезеңдерді, тапсырмаларды және тексеру сұрақтарын қосып, сабақты сілтемемен бөлісуге немесе JSON файлына шығаруға болады.


## Іске қосу

```bash
pnpm install
pnpm dev                 # http://localhost:3000
```

Қосымша API-ды іске қосу:

```bash
COOKIE_SECRET=$(openssl rand -hex 32) pnpm --filter @inside-tech/api dev   # http://127.0.0.1:4000
```

## Тексеру

```bash
pnpm typecheck
pnpm test                                   # unit + API
pnpm --filter @inside-tech/web build
pnpm --filter @inside-tech/web e2e          # Playwright
```

## Статикалық нұсқа

```bash
FULL_HTML=1 pnpm --filter @inside-tech/web build:artifact   # apps/web/dist-artifact/
```

Бір беттік нұсқа шығады: маршрутизация hash арқылы жүреді (`#ai`, `#arch`, `#blackbox`), ал worker бөлек файлда тұрады. Worker қолжетімсіз болса, симуляция негізгі ағында жұмыс істейді. Жинақты HTTP арқылы аш немесе GitHub Pages сияқты статикалық хостингке жарияла.
